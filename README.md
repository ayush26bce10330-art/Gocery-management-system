# Grocery Management System

## 1. Project Overview

The Grocery Management System is a Python-based project designed to manage basic grocery store activities.

The system allows the user to manage products, record sales and purchases, and view reports.

The project is developed as a console-based application using Python.

## 2. Features

The main features of the system are:

- Add a product
- View products
- Search for a product
- Update product information
- Delete a product
- Record a sale
- Record a purchase
- View reports
- Store product, sales and purchase information in files
- Validate user input

## 3. Technologies Used

- Python
- Python functions
- Lists
- Dictionaries
- File handling
- Exception handling
- VS Code

## 4. Project Structure

The project contains the following Python files:

- `main.py` - Main menu and program control
- `products.py` - Product management
- `sales.py` - Sales management
- `purchases.py` - Purchase management
- `reports.py` - Reports
- `file_handler.py` - File storage and retrieval
- `validation.py` - Input validation
