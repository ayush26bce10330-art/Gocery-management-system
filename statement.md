# Project Statement

## 1. Problem Statement

Managing grocery products manually can make it difficult to keep track of product information, stock quantities, sales and purchases.

The Grocery Management System provides a simple Python-based system for managing these activities through a console application.

## 2. Scope of the Project

The project focuses on basic grocery management activities.

The system allows the user to:

- Manage product information
- Maintain product quantities
- Record sales
- Record purchases
- View basic reports
- Store information using files

The project is designed as a simple console-based Python application.

## 3. Target Users

The system is intended for users who need to manage basic grocery store information and activities.

## 4. High-Level Features

The major features of the system are:

1. Product Management
2. Sales Management
3. Purchase Management
4. Report Generation
5. File-based Data Storage
6. Input Validation

## 5. Objectives

The objectives of the project are:

- To create a simple grocery management system using Python.
- To manage product information.
- To keep track of product quantities.
- To record sales and purchases.
- To generate basic reports.
- To apply Python programming concepts in a practical project.
